# Co-Op Consulting Group website

Static site. No build step.

## Deploy on Vercel
1. Upload all of these files to a GitHub repo, keeping the folder structure.
2. In Vercel, go to Add New → Project, import the repo, set Framework Preset to "Other", and Deploy.

## Editing
- Page text lives in the .html / .dc.html files and can be edited in GitHub's web editor. Committing a change redeploys automatically.
- Service page copy: ServicePage.dc.html (the SERVICES object).
- Header and footer: SiteHeader.dc.html and SiteFooter.dc.html.
- Photos: assets/photos/. Replace a file with the same name to swap a photo.
